# 안전교육

건설현장 고위험 작업 18종의 안전교육, 자율점검, 근로자 서명을 안드로이드 스마트폰과 갤럭시탭에서 진행하는 웹앱(PWA)입니다.
서버 없이 동작하며, 기록은 지도요원 기기에만 저장됩니다.

- 앱 주소: https://samsara36524.github.io/safety-edu/
- 설치: 크롬으로 접속 → 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**. 설치 후에는 인터넷이 없어도 열립니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 교육자료 | 18개 작업별 개요, 사고사례, 예방 그림, 핵심 안전수칙, 근로자 준수사항, 교육 영상, 원본 자료 |
| 자율점검 | 원본 자율점검표 항목을 양호 / 미흡 / 해당없음으로 판정, 미흡 항목은 메모와 사진 첨부 |
| 현장 서명 | 지도요원 화면의 QR을 근로자 폰으로 찍음 → 확인·서명 → 근로자 화면의 결과 QR을 지도요원이 스캔 |
| 직접 서명 | 폰이 없는 근로자는 지도요원 기기에서 바로 서명 |
| 원격 교육 | 교육 링크를 카톡·문자로 보냄 → 근로자가 서명 후 결과 링크를 회신 → 지도요원이 링크를 누르면 자동으로 추가 |
| 결과 저장 | 교육사진 1장(필수)과 함께 `안전교육_현장명_날짜` 폴더에 PDF, 페이지별 이미지, 교육사진 저장 |
| 확장 | 새 교육자료를 만들거나 기존 자료를 복사해 수정, 파일로 내보내기·가져오기 |

서명은 교육 1건당 최대 6명까지 받습니다.

### 현장·근로자 등록과 검색
- 교육한 현장(현장명·교육장소)과 서명한 근로자 이름은 자동으로 등록됩니다. 홈 → **현장·근로자**에서 직접 등록·삭제할 수도 있습니다.
- 새 교육의 현장명, 근로자 이름 칸은 등록된 목록에서 검색해 고를 수 있습니다. 초성 검색도 됩니다(예: `ㅎㄱㄷ` → 홍길동).
- 지도요원 기기에서 서명할 때 이름을 고르면 그 사람의 **이전 서명**(최근 5개)이 나옵니다. 누르면 서명 칸에 불러오고, 결과표의 확인방식에는 `현장(이전 서명)`으로 표시됩니다. 서명 칸에 새로 쓰면 새 서명으로 저장됩니다.
- 근로자에게 보내는 QR·원격 링크에는 그 현장의 등록 근로자 이름(최근 40명)이 담깁니다. 근로자는 자기 이름을 검색해서 고를 수 있습니다.

### 비밀번호
- 앱을 열 때와 근로자가 QR·링크로 들어올 때 **숫자 6자리 비밀번호**가 맞아야 화면이 보입니다. 한 번 맞히면 브라우저(앱)를 닫을 때까지 다시 묻지 않습니다.
- 설정 → **비밀번호**에서 바꿀 수 있습니다. 바꾸면 이후 보내는 QR·링크부터 새 비밀번호가 적용되고, 이미 보낸 링크는 그때의 비밀번호를 씁니다.
- 비밀번호는 원문 대신 해시로만 저장됩니다. 다만 서버 없이 화면만 막는 방식이라 강한 보안 수단은 아닙니다. 공개 저장소의 교육자료 파일은 주소를 알면 직접 볼 수 있습니다.

## 서버 없이 원격 결과를 주고받는 방식

- 교육 링크와 결과 링크에는 필요한 내용(현장명, 작업, 이름, 서명 획)이 압축되어 주소의 `#` 뒤에 들어갑니다.
- `#` 뒤의 내용은 GitHub 서버로 전송되지 않습니다. 개인정보는 주고받는 두 기기에만 남습니다.
- 결과 링크는 **교육을 만든 지도요원 기기의 크롬(또는 설치한 앱)**에서 열어야 저장됩니다.
  카카오톡 안의 브라우저에서 열리면 화면의 **[크롬으로 열기]**를 누르세요. 그래도 안 되면 앱에서 **[결과 코드 붙여넣기]**를 사용합니다.

## 저장 폴더

- 폴더 지정 저장은 브라우저가 지원할 때만 쓸 수 있습니다(PC 크롬·엣지 등). 지원하면 **[지정 폴더에 저장]** 버튼이 나타납니다.
- 안드로이드 크롬은 아직 폴더 지정을 지원하지 않습니다. 다음 중 하나로 저장하세요.
  - **[ZIP으로 저장]**: `다운로드` 폴더에 저장됩니다.
  - **[공유]**: 구글드라이브나 원드라이브의 원하는 폴더에 바로 올립니다.

## 교육자료 추가 (확장)

### 페이지 자료 등록 (PDF·이미지·촬영)
교육자료 → **[＋ 페이지 자료 등록]** → 제목을 넣고 페이지를 추가합니다.
- **PDF 추가**: 쪽마다 한 페이지로 나뉘어 등록됩니다.
- **이미지 추가**: 여러 장을 한 번에 고를 수 있고, 한 장이 한 페이지가 됩니다.
- **카메라로 촬영**: 종이 자료를 찍어 페이지로 넣습니다.
- ↑↓로 순서를 바꾸고 쪽마다 설명을 붙일 수 있습니다. 근로자 확인 항목, 재해유형, 핵심수칙, 자율점검표는 선택입니다.

등록한 자료는 기본 자료와 똑같이 새 교육의 작업 선택에 나옵니다.
- 교육 단계: **▶ 전체화면으로 보기**로 넘겨 가며 설명합니다(좌우 밀기, 화면 좌우 누르기, 방향키).
- 서명 단계: 근로자 확인 항목에 체크하고 서명합니다.
- 결과 PDF: 교육한 페이지가 한 줄에 3쪽씩 작은 그림으로 들어갑니다.
- 원격 링크: 페이지 그림은 전달되지 않습니다. 근로자 화면에는 "지도요원이 화면으로 설명합니다"라는 안내만 나옵니다.

### 앱에서 추가 (내 기기에만 저장)
교육자료 → **[새 교육자료]** 또는 자료 화면의 **[복사해서 새 자료]**를 누릅니다.

자율점검표는 한 줄에 한 항목씩 입력하며, 다음 규칙을 따릅니다.
```
# 사전 확인                ← '#'으로 시작: 구분
! 작업계획서를 작성한다.     ← '!'로 시작: 핵심 항목(파란 글씨)
* 2m 이상 작업 시           ← '*'로 시작: 바로 위 항목의 참고 설명
안전모를 착용한다.          ← 일반 항목
```
추가한 자료로 원격 교육을 하면 글 내용만 링크에 담겨 전달되고, 사진과 그림은 빠집니다.

### 모든 사용자에게 배포 (사진·그림 포함)
1. 앱에서 자료를 만든 뒤 **[내보내기]**로 JSON 파일을 받습니다.
2. 파일 내용(배열)을 이 저장소의 `data/extra.json` 배열에 추가합니다. 그림은 `img/` 폴더에 올리고 경로를 `img/파일명.jpg`로 적어도 됩니다.
3. 커밋하면 GitHub Pages에 자동으로 반영되어, 모든 기기에서 **추가 자료**로 보입니다.

## 폴더 구조

```
index.html            화면 틀
css/app.css           디자인 (결과 보고서 A4 양식 포함)
js/app.js             화면·교육 진행·서명·원격·저장
js/report.js          결과 PDF·페이지 이미지 생성
js/sig.js             서명 패드와 서명 압축
js/codec.js           링크·QR용 데이터 압축
js/qr.js              QR 생성·카메라 스캔
js/db.js              기기 내 저장소(IndexedDB)
data/topics.json      기본 교육자료 18종 (원본: 안전교육자료.pdf)
data/extra.json       추가 배포용 교육자료
img/                  사진·예방 그림, img/src/ 원본 페이지
vendor/               qrcode-generator, jsQR, html2canvas, jsPDF, JSZip, pdf.js(PDF 나누기)
sw.js                 오프라인 지원
```

## 주의

- 교육 기록은 기기의 브라우저 저장소에 있습니다. 브라우저 데이터를 지우거나 기기를 바꾸면 사라지므로, 결과 파일은 반드시 저장해 두세요.
- 앱 코드와 자료는 인터넷이 연결되어 있으면 항상 최신본을 받습니다. 오프라인일 때만 저장본을 씁니다.
- 코드를 고친 뒤에는 `index.html`의 `APP_VERSION`과 파일 주소 뒤 `?v=`, `sw.js`의 `CACHE` 버전을 함께 올려야 합니다.
- 교육자료 출처: 안전보건공단(KOSHA) 건설현장 고위험 작업 안전수칙·자율점검표. 영상 링크는 원본 자료의 QR코드에서 추출했습니다.
