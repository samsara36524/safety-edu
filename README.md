# 안전지도

사람인안전지도사사무소의 건설현장 안전교육 · TBM 일지 앱입니다.

건설현장 고위험 작업 18종의 안전교육, 자율점검, 근로자 서명을 안드로이드 스마트폰과 갤럭시탭에서 진행하는 웹앱(PWA)입니다.
서버 없이 동작하며, 기록은 지도요원 기기에만 저장됩니다.

- 앱 주소: https://samsara36524.github.io/safety-edu/
- 설치(홈 화면 앱 등록): 휴대폰 크롬·삼성 인터넷으로 접속 → 홈 화면의 **홈 화면에 앱 설치** 버튼, 또는 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**. 홈 화면에 **안전지도** 아이콘이 생기고, 길게 누르면 **안전교육 시작 / TBM 시작** 바로가기가 나옵니다. 아이폰은 Safari → 공유 → **홈 화면에 추가**. 설치 후에는 인터넷이 없어도 열립니다.
- 결과지(안전교육 결과, TBM 일지)에는 사람인안전지도사사무소 로고와 사무소명이 들어갑니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 교육자료 | 18개 작업별 개요, 사고사례, 예방 그림, 핵심 안전수칙, 근로자 준수사항, 교육 영상, 원본 자료 |
| 자율점검 | 원본 자율점검표 항목을 양호 / 미흡 / 해당없음으로 판정, 미흡 항목은 메모와 사진 첨부 |
| 현장 서명 | 지도요원 화면의 QR을 근로자 폰으로 찍음 → 확인·서명 → 근로자 화면의 결과 QR을 지도요원이 스캔 |
| 직접 서명 | 폰이 없는 근로자는 지도요원 기기에서 바로 서명 |
| 원격 교육 | 교육 링크를 카톡·문자로 보냄 → 근로자가 서명 후 결과 링크를 회신 → 지도요원이 링크를 누르면 자동으로 추가 |
| 결과 저장 | 교육사진 1장(필수)과 함께 `안전교육_현장명_날짜` 폴더에 PDF, 페이지별 이미지, 교육사진 저장 |
| 확장 | 새 교육자료를 만들거나 기존 자료를 복사해 수정, 파일로 내보내기·가져오기 |

서명은 교육 1건당 최대 6명까지 받습니다.

서명은 붓펜으로 쓴 것처럼 남습니다. S펜 등 펜은 누르는 힘에 따라, 손가락은 쓰는 속도에 따라(천천히 쓰면 조금 굵게, 빠르게 쓰면 조금 가늘게) 굵기가 바뀌고, 획의 시작과 끝은 살짝 가늘어집니다. 서명 칸 아래 **굵기** 버튼(5단계)으로 전체 굵기를 고를 수 있고, 고른 굵기는 기기에 기억됩니다. 굵기는 서명과 함께 저장되어 결과지와 이전 서명 불러오기에도 그대로 반영됩니다.

## TBM 일지 (작업 전 안전점검회의)

지도요원이 현장 작업자와 TBM을 진행하고, 결과를 **A4 한 장 PDF**로 만들어 시공사에 전달합니다.
시공사는 출력해서 결재칸(**관리감독자 · 안전보건관리책임자**)에 수기로 결재하고 보관합니다.

| 단계 | 내용 |
|---|---|
| 기본정보 | 현장명(검색), TBM 장소, 날씨, 날짜·시작·종료, 작업명, 금일 작업내용, 위험성평가 실시 여부 |
| | **양식 선택**: 사진 포함 양식 / 사진 없는 양식 |
| | **TBM 리더**: 소속·직책·성명 (수정 가능, 다음 TBM에도 유지) |
| | 작업자 안전의식 자가진단(8문항) 받기 (선택) |
| 위험요인 | 잠재위험요인 3개와 대책: 목록에서 고르거나 직접 입력 |
| | 목록 = 내가 쓴 위험요인 + 기본 교육자료 18종의 사고사례 54개 |
| | 중점위험 1개 선정, 작업 전 조치 여부(예/아니오, 조치내용) |
| 안내 | 금일 작업·위험요인·중점위험을 큰 글씨(전체화면)로 설명, 전달사항·일일 안전점검 결과 입력 |
| 서명 | TBM 리더 서명 + 작업자 **6명**까지 (현장 QR 또는 이 기기에서 서명, 이전 서명 불러오기 가능) |
| 사진 | 사진 포함 양식만: TBM 사진 1매 (필수) |
| 결과 | 근로자 의견, 작업 후 종료 미팅 입력(비우면 수기용 빈칸) → PDF 저장·공유, JPG 저장 |

- 같은 현장은 **지난 TBM 불러오기**(또는 TBM 목록의 **이 내용으로 새 TBM**)로 작업명·위험요인·리더 정보를 한 번에 채웁니다. 날짜, 서명, 사진은 새로 받습니다.
- TBM은 현장 대면 진행이 원칙이라 원격 링크는 쓰지 않습니다.

## 관리체계 점검 (과태료 부과기준)

지도요원이 건설현장이 갖춰야 할 안전보건 관리체계를 **과태료 부과기준 요약(법 제175조) 38개 항목**으로 현장소장에게 설명하고 결과를 남깁니다. (홈 → **관리체계 점검**)

- 상단: 현장명, 점검일, **지도요원 이름·서명**, **현장소장 이름·서명** (같은 현장은 지난 점검의 현장소장 이름 자동 입력, 이름별 이전 서명 불러오기)
- 항목마다 **해당여부**를 고르고 비고 입력: **○ 해당**, **△ 발생 시**(해당 상황이 생기면 적용), **공백 미해당** (3쪽 추가 항목도 같음)
- **3쪽 추가(선택)**: 체크하면 지도요원이 추가로 점검할 준수사항이 나옵니다. 여기 등록한 항목(준수해야 할 내용·관련법)은 **모든 현장 공통**이라 어느 현장의 점검을 열어도 같은 목록이 불러와지고, 추가·수정·삭제도 모든 현장에 반영됩니다. **해당여부·비고만 현장(점검)마다 따로** 기록됩니다(최대 20개, 결과지는 최소 12행이라 남는 행은 수기 기재용).
- 결과: **PDF 1개**(1쪽 1~18번, 2쪽 19~38번, 선택 시 3쪽 추가 점검)와 **쪽별 이미지**(쪽마다 저장, 함께 공유)
- 항목·금액은 js/law.js의 ITEMS에 있습니다.

## 장비측정

지도요원이 측정장비로 현장을 측정한 결과를 장비별로 기록하고 사진을 붙여 PDF·이미지로 저장합니다. (홈 → **장비측정**)

- 장비: 산소농도, 가스농도, 접지저항(KEC), 절연저항(KEC), 조도계, 저압검전기, 접지선시험기, 기타(장비명·법적기준 직접 입력)
- **체크한 장비만** 작성: 측정장소 · 측정값 · 판정(표시 안 함/적합/부적합) · 지도사항 · 사진 1장
- 측정장소·측정값·지도사항은 **지난 입력 불러오기**로 채울 수 있습니다. 장비별로 쌓이며 현장과 관계없이 공통입니다. (결과지를 만들 때 저장, 장비·항목별 최근 30개)
- 법적기준 문구는 화면에서 고칠 수 있고 **이 기준을 기본값으로 기억**으로 다음 측정에도 씁니다.
- 결과지는 **A4 한 장에 장비 3개**씩. 3개를 넘으면 다음 장으로 넘어갑니다. PDF(여러 장) 또는 이미지 1개(여러 장이면 세로로 이어붙임)로 저장합니다.

### 현장·근로자 등록과 검색
- 홈 → **현장·근로자**에서 관리 중인 현장을 **등록·수정·삭제**합니다. 항목: 현장명, 시공사, 현장 주소, 기본 장소(교육·TBM 장소로 자동 입력), 현장 담당자, 연락처, 메모.
- 안전교육·TBM·장비측정의 현장명 칸 아래 **현장 선택**(등록 현장 목록), **＋ 새 현장** 버튼이 있고, 등록되지 않은 이름을 쓰면 **이 이름으로 등록**이 나옵니다. 등록 현장은 **정보 수정**도 바로 할 수 있습니다.
- 현장명을 바꾸면 그 현장의 교육·TBM·장비측정 기록의 현장명도 함께 바뀝니다. 교육한 현장과 서명한 근로자는 자동으로도 등록됩니다.
- 현장마다 **인원 명단(이름·전화번호)**을 관리합니다. 한 명씩 추가·수정·삭제하거나, **여러 명 붙여넣기**(엑셀·카톡·문자에서 복사한 `이름 전화번호` 목록), 안드로이드 크롬에서는 **휴대폰 연락처에서 가져오기**로 넣습니다. 전화번호를 누르면 바로 전화가 걸리고, 번호로도 검색됩니다.
- 전화번호는 이 기기에만 저장되며 근로자에게 보내는 QR·링크에는 담기지 않습니다(이름만).
- 새 교육의 현장명, 근로자 이름 칸은 등록된 목록에서 검색해 고를 수 있습니다. 초성 검색도 됩니다(예: `ㅎㄱㄷ` → 홍길동).
- 지도요원 기기에서 서명할 때 이름을 고르면 그 사람의 **이전 서명**(최근 5개)이 나옵니다. 누르면 서명 칸에 불러오고, 결과표의 확인방식에는 `현장(이전 서명)`으로 표시됩니다. 서명 칸에 새로 쓰면 새 서명으로 저장됩니다.
- 근로자에게 보내는 QR·원격 링크에는 그 현장의 등록 근로자 이름(최근 40명)이 담깁니다. 근로자는 자기 이름을 검색해서 고를 수 있습니다.

### 비밀번호
- 앱을 열 때와 근로자가 QR·링크로 들어올 때 **숫자 6자리 비밀번호**가 맞아야 화면이 보입니다. 한 번 맞히면 브라우저(앱)를 닫을 때까지 다시 묻지 않습니다.
- 설정 → **비밀번호**에서 바꿀 수 있습니다. 바꾸면 이후 보내는 QR·링크부터 새 비밀번호가 적용되고, 이미 보낸 링크는 그때의 비밀번호를 씁니다.
- 비밀번호는 원문 대신 해시로만 저장됩니다. 다만 서버 없이 화면만 막는 방식이라 강한 보안 수단은 아닙니다. 공개 저장소의 교육자료 파일은 주소를 알면 직접 볼 수 있습니다.

## 서버 없이 원격 결과를 주고받는 방식

- 교육 링크와 결과 링크에는 필요한 내용(현장명, 작업, 이름, 서명 획)이 압축되어 주소의 `#` 뒤에 들어갑니다.
- `#` 뒤의 내용은 GitHub 서버로 전송되지 않습니다. 개인정보는 주고받는 두 기기에만 남습니다.
- 결과 링크는 **교육을 만든 지도요원 기기의 크롬(또는 설치한 앱)**에서 열어야 저장됩니다.
  카카오톡 안의 브라우저에서 열리면 화면의 **[크롬으로 열기]**를 누르세요. 그래도 안 되면 앱에서 **[결과 코드 붙여넣기]**를 사용합니다.

## 교육자료 추가 (확장)

### 페이지 자료 등록 (PDF·이미지·촬영)
교육자료 → **[＋ 페이지 자료 등록]** → 제목을 넣고 페이지를 추가합니다.
- **PDF 추가**: 쪽마다 한 페이지로 나뉘어 등록됩니다.
- **이미지 추가**: 여러 장을 한 번에 고를 수 있고, 한 장이 한 페이지가 됩니다.
- **카메라로 촬영**: 종이 자료를 찍어 페이지로 넣습니다.
- ↑↓로 순서를 바꾸고 쪽마다 설명을 붙일 수 있습니다. 근로자 확인 항목, 재해유형, 핵심수칙, 자율점검표는 선택입니다.

등록한 자료는 기본 자료와 똑같이 새 교육의 작업 선택에 나옵니다.
- 교육 단계: **▶ 전체화면으로 보기**로 넘겨 가며 설명합니다(좌우 밀기, 화면 좌우 누르기, 방향키).
- 서명 단계: 근로자 확인 항목에 체크하고 서명합니다.
- 결과 PDF: 교육한 페이지가 한 줄에 3쪽씩 작은 그림으로 들어갑니다.
- 원격 링크: 페이지 그림은 전달되지 않습니다. 근로자 화면에는 "지도요원이 화면으로 설명합니다"라는 안내만 나옵니다.

### 앱에서 추가 (내 기기에만 저장)
교육자료 → **[새 교육자료]** 또는 자료 화면의 **[복사해서 새 자료]**를 누릅니다.

자율점검표는 한 줄에 한 항목씩 입력하며, 다음 규칙을 따릅니다.
```
# 사전 확인                ← '#'으로 시작: 구분
! 작업계획서를 작성한다.     ← '!'로 시작: 핵심 항목(파란 글씨)
* 2m 이상 작업 시           ← '*'로 시작: 바로 위 항목의 참고 설명
안전모를 착용한다.          ← 일반 항목
```
추가한 자료로 원격 교육을 하면 글 내용만 링크에 담겨 전달되고, 사진과 그림은 빠집니다.

### 모든 사용자에게 배포 (사진·그림 포함)
1. 앱에서 자료를 만든 뒤 **[내보내기]**로 JSON 파일을 받습니다.
2. 파일 내용(배열)을 이 저장소의 `data/extra.json` 배열에 추가합니다. 그림은 `img/` 폴더에 올리고 경로를 `img/파일명.jpg`로 적어도 됩니다.
3. 커밋하면 GitHub Pages에 자동으로 반영되어, 모든 기기에서 **추가 자료**로 보입니다.

## 주의

- 교육 기록은 기기의 브라우저 저장소에 있습니다. 브라우저 데이터를 지우거나 기기를 바꾸면 사라지므로, 결과 파일은 반드시 저장해 두세요.
- 앱 코드와 자료는 인터넷이 연결되어 있으면 항상 최신본을 받습니다. 오프라인일 때만 저장본을 씁니다.
- 코드를 고친 뒤에는 `index.html`의 `APP_VERSION`과 파일 주소 뒤 `?v=`, `sw.js`의 `CACHE` 버전을 함께 올려야 합니다.
- 교육자료 출처: 안전보건공단(KOSHA) 건설현장 고위험 작업 안전수칙·자율점검표. 영상 링크는 원본 자료의 QR코드에서 추출했습니다.
